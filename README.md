# Atelier Shell

Un site statique en français pour s’exercer aux commandes Linux, à Git et GitHub, au shell et aux conversions entre décimal et binaire.

## Lancer en local

Ouvrez simplement `index.html` dans un navigateur récent. Le site ne nécessite ni installation, ni serveur, ni dépendance. Les fichiers `index.html`, `style.css` et `app.js` doivent rester dans le même dossier.

## Déployer

Déposez le contenu de ce dossier sur Netlify, ou publiez le dossier comme site statique avec GitHub Pages, Cloudflare Pages ou un hébergement web classique. Le fichier `index.html` est à la racine.

## Contenu

- 5 chapitres de commandes et notions, avec exemples et questions interactives.
- Une page « Quiz complet » rassemble toutes les questions. Le chronomètre démarre au lancement et une explication apparaît après chaque réponse.
- Exercices de compréhension, de choix de commande et de complétion, avec affichage adapté aux petits écrans.
- Convertisseur décimal/binaire avec détail des étapes.
- Progression sauvegardée dans le stockage local du navigateur.

Les commandes sont expliquées et simulées à des fins pédagogiques : le site ne lance aucune commande sur votre ordinateur.
